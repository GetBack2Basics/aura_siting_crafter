🤖 Conversational Spatial AI ("Ask AI") Architecture & Deterministic Sandbox

Zero-Hallucination Safe

AURA Siting Crafter eliminates LLM hallucination risks in statutory and financial infrastructure due diligence by implementing a Deterministic Text-to-Spatial-SQL Sandbox. Natural language queries are strictly compiled into standard SQL expressions and executed 100% inside your local browser via DuckDB-WASM against pre-certified spatial tables.

🔒 1. Read-Only Schema Containment

The AI compiler has zero write or mutating privileges. It operates solely against a certified dictionary of 15.4M+ parcel geometries, transmission line vectors, and statutory hazard tables.

⚡ 2. In-Browser DuckDB-WASM Execution

SQL generated by the user's plain-English prompt (e.g. "Show sites in NSW within 1.5km of 330kV lines") runs locally in milliseconds at $0.00 marginal cloud server cost.

🔍 3. Inspectable & Editable SQL Trail

Every query reveals the exact SQL syntax in the interactive query editor. Users can inspect, tweak, or extend WHERE clauses and re-execute immediately via Ctrl+Enter.
