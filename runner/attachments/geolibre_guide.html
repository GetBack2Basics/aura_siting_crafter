What is the GeoLibre Project Spec?
The aura-siting-crafter.geolibre.json file contains the declarative spatial definition of this national siting model, including all candidate hubs, MCE suitability formulas, thematic vector styling, and direct S3 lakehouse stream configurations.
How to Use in Desktop GIS (GeoLibre, QGIS, ArcGIS Pro):
1
Download the JSON Project Spec using the button below.
2
Open with GeoLibre App / WebGIS: Launch the GeoLibre desktop application or open the GeoLibre WebGIS (geolibre.app/demo) and choose "Project" → "Open Project..." (or drag & drop) → select aura-siting-crafter.geolibre.json.
3
Direct S3 Lakehouse Streaming: GeoLibre connects directly to the S3 Iceberg/GeoParquet endpoints for live querying and spatial joins without downloading full datasets locally.
4
QGIS / Python GIS / DuckDB Access: Import candidate GeoJSON features directly into QGIS, or read candidate parquet with read_parquet('s3://wherobots-user-storage/aura_siting/candidates/datacenter_candidates_national.parquet') in DuckDB or GeoPandas.
🌐 Open in GeoLibre (geolibre.app/demo)
