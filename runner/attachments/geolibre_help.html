🛠️ How the Tech Works (Under the Hood)
1. Streaming Data Straight from the Cloud: Instead of downloading huge files or running heavy servers, the map grabs only the exact slices of data it needs from cloud storage as you pan and zoom.
2. Instant Scoring in Your Browser ($0 Server Cost): When you adjust weights for power, water, or environment, your browser does all the math locally with DuckDB. You get instant updates without paying for cloud servers.
3. Ask Questions in Plain English: Type everyday questions like "Show sites in NSW within 1.5km of 330kV lines" and the system automatically turns your words into database queries.
4. Open in Desktop GIS / WebGIS (GeoLibre WebGIS / QGIS): Download a single project file (aura-siting-crafter.geolibre.json) to open the exact same map and data in desktop tools or the GeoLibre Web App (geolibre.app/demo).
5. Official Australian Public Data: All property boundaries, power lines, water corridors, and protected areas are pulled straight from official government and industry sources (AEMO, Geoscience Australia, BoM, and NSW Spatial Services).
