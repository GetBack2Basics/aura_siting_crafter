Next Steps & Technical Roadmap

Executive Summary

Following the deployment of the AURA Siting Crafter national suitability model and the GeoLibre WebGIS platform, the immediate technical priorities focus on high-resolution vector tile streaming, direct client-side Parquet querying, multi-model LLM integration, and state digital twin exports.

1. High-Resolution Vector Tile Pyramids (PMTiles & MVT)

  1. Distributed Vector Tiling: Implement Apache Sedona / Tilezen pipelines to generate multi-resolution PMTiles for the 15.4M parcel national cadastre and 1.18M ABS meshblocks.
  2. Sub-Second Client Rendering: Stream parcel boundaries directly into MapLibre GL JS at zoom levels 14–18 using byte-range HTTP requests, eliminating GeoJSON payload bottlenecks.
  3. Automated Cache Invalidation: Establish ETag/hash-based cache update triggers when authoritative state cadastral datasets are refreshed.

2. Direct Client-Side Parquet Range Streaming

  1. Zero-Proxy Architecture: Enable browser-native DuckDB-WASM to execute HTTP byte-range queries directly against S3/GCS GeoParquet tables (s3://wherobots-user-storage/aura_siting/) without routing queries through the Cloud Run backend.
  2. Spatial Hilbert-Curve Partitioning: Partition national datasets along Hilbert space-filling curves to minimize HTTP range request counts during bounding box queries.
  3. Client Memory Optimization: Implement automatic row-group pruning and memory garbage collection for low-memory mobile browser sessions.

3. Multi-Model LLM OpenRouter BYOK (Bring-Your-Own-Key) Integration

  1. Dual-Tier Model Selection: Provide a free tier powered by Google Gemini 2.5 Flash on Cloud Run alongside a Bring-Your-Own-Key (BYOK) OpenRouter interface.
  2. Advanced Spatial Reasoning: Allow users to select specialized reasoning models (e.g. Claude 3.5 Sonnet, GPT-4o, DeepSeek-R1) directly within the GeoLibre settings drawer for complex planning queries.
  3. Secure Local Storage: Store user API keys exclusively within browser localStorage, never logging or transmitting keys to backend servers.

4. Fine-Grained Regional Precinct Expansion (AURA_REGION)

  1. Automated Slope & Riparian Ingest: Run targeted 1m LiDAR DEM slope analysis and 30m riparian buffer clipping for declared Renewable Energy Zones in Queensland (Central/North QLD REZs) and Victoria (Latrobe Valley / Western VIC).
  2. Net Developable Area (NDA) Quantification: Automate statutory land subtraction (easements, mine subsidence, flood overlays) for all major national energy transition hubs.

5. State Spatial Digital Twin & TerriaJS Integration

  1. Standardized GeoLibre Project Spec: Maintain aura-siting-crafter.geolibre.json with direct compatibility for 1-click loading into the NSW Spatial Digital Twin and National Map.
  2. Automated Catalog Sync: Export OGC API - Features and STAC catalog endpoints for seamless ingestion by state geospatial agencies (NSW Spatial Services, Geoscience Australia).
