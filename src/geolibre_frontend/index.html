What is the GeoLibre Project Spec?
The aura-siting-crafter.geolibre.json file contains the full declarative spatial definition of this national siting model, including all 16 candidate hubs, MCE suitability formulas, thematic vector styling, and direct S3 lakehouse stream configurations.
How to Use in Desktop GIS (GeoLibre, QGIS, ArcGIS Pro):
1
Download the JSON Project Spec using the button below.
2
Open with GeoLibre App: Launch the GeoLibre desktop application or web GIS and choose "Import Project" → select aura-siting-crafter.geolibre.json.
3
Direct S3 Lakehouse Streaming: GeoLibre connects directly to the S3 Iceberg/GeoParquet endpoints for live querying and spatial joins without re-downloading gigabytes of data.
4
QGIS / Python GIS / DuckDB Access: Import the candidate GeoJSON features directly into QGIS, or read candidate parquet with read_parquet('s3://wherobots-user-storage/aura_siting/candidates/datacenter_candidates_national.parquet') in DuckDB or GeoPandas.
